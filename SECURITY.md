# Politique de sécurité — TalentClear

## Présentation

TalentClear accorde une importance particulière à la sécurité de sa plateforme, de son code source et des données pouvant être traitées par ses services.

Cette page présente la procédure à suivre pour signaler de manière responsable une éventuelle vulnérabilité de sécurité.

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité ou un problème de sécurité concernant TalentClear, merci de ne pas publier les informations techniques dans une issue publique GitHub.

Nous vous invitons à transmettre votre signalement de manière confidentielle à :

**talentclear@outlook.fr**

L'objet du message peut être :

**[SECURITY] Signalement de vulnérabilité**

## Informations à fournir

Afin de permettre une analyse efficace, merci d'indiquer autant que possible :

- Une description claire de la vulnérabilité
- Le composant ou la fonctionnalité concernée
- Les étapes permettant de reproduire le problème
- L'impact potentiel identifié
- Les versions ou environnements concernés
- Toute information technique permettant de faciliter l'analyse
- Une preuve de concept, uniquement si elle est nécessaire à la compréhension du problème

Merci de ne jamais transmettre de mots de passe, clés API, tokens, données personnelles ou autres informations confidentielles dans votre signalement.

## Traitement des signalements

Chaque signalement de sécurité sera examiné avec attention.

Après réception, nous nous efforcerons de :

1. Accuser réception du signalement.
2. Vérifier et analyser le problème signalé.
3. Évaluer son impact et son niveau de criticité.
4. Mettre en place les mesures correctives nécessaires lorsque cela est confirmé.
5. Publier, lorsque cela est pertinent, une correction ou une information de sécurité sans divulguer de données sensibles.

Le délai de traitement peut varier selon la complexité et la criticité du problème.

## Divulgation responsable

Nous demandons aux personnes signalant une vulnérabilité de respecter une démarche de divulgation responsable.

Merci notamment de :

- Ne pas exploiter une vulnérabilité au-delà de ce qui est nécessaire pour la démontrer.
- Ne pas accéder, modifier, supprimer ou divulguer des données appartenant à d'autres utilisateurs.
- Ne pas interrompre ou dégrader les services de TalentClear.
- Ne pas publier publiquement une vulnérabilité avant d'avoir permis son analyse et, lorsque cela est possible, sa correction.

## Données sensibles

Ne transmettez jamais de données personnelles, identifiants, mots de passe, clés secrètes, tokens d'accès ou autres informations confidentielles dans une issue publique ou dans le dépôt GitHub.

Si une information sensible a été exposée accidentellement, elle doit être considérée comme potentiellement compromise et traitée rapidement.

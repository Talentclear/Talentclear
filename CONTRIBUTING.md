# Contribuer à TalentClear

Merci de votre intérêt pour TalentClear.

TalentClear est une plateforme spécialisée dans l’emploi et le recrutement en hôtellerie-restauration. Les contributions doivent respecter l’objectif du projet : proposer une expérience professionnelle, simple, claire et adaptée aux besoins du secteur.

## Avant de contribuer

- Consultez les issues existantes avant d’en créer une nouvelle.
- Vérifiez que votre contribution est cohérente avec la feuille de route du projet.
- Ne publiez jamais de données personnelles, mots de passe, clés API ou autres secrets.
- Respectez le Code of Conduct du projet.

## Proposer une amélioration

Pour proposer une fonctionnalité ou une amélioration :

1. Ouvrez une issue de type **Feature request**.
2. Décrivez clairement le besoin.
3. Expliquez l’impact attendu pour les candidats, employeurs, recruteurs ou organismes de formation.
4. Précisez, si possible, les critères permettant de valider l’évolution.

## Signaler un problème

Utilisez le modèle **Bug report** et fournissez autant d’informations que possible pour permettre la reproduction du problème.

## Pull requests

Toute modification importante doit être associée à une issue lorsque cela est pertinent.

Une pull request doit :

- expliquer clairement la modification ;
- rester ciblée sur un objectif précis ;
- éviter les changements inutiles ;
- préserver la sécurité et la confidentialité des données ;
- être testée avant sa proposition.

## Sécurité

Ne publiez jamais de secret dans le dépôt.

Pour signaler une vulnérabilité de sécurité, consultez la politique de sécurité du dépôt :

https://github.com/Talentclear/Talentclear/security/policy
